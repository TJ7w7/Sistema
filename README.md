# Sistema POS para Restaurante

Proyecto enfocado en la automatización de procesos comerciales dentro de un restaurante, tales como la toma de pedidos, 
la atención de mesas y el control básico de inventario.

El objetivo principal de este sistema fue aplicar de manera práctica la lógica de negocio en el backend y entender el flujo de datos relacionales en un entorno real.

##  Tecnologías Utilizadas
*   **Lenguaje:** C#
*   **Framework Backend:** ASP.NET
*   **Base de Datos:** SQL Server
*   **Formato de Datos:** Estructuras JSON para el flujo de información interno

##  Funcionalidades Principales
*   **Gestión de Pedidos:** Registro y flujo de comandas asociadas a mesas específicas.
*   **Control de Inventario:** Actualización y seguimiento de los insumos o platos disponibles en el menú.
*   **Persistencia de Datos:** Base de datos relacional diseñada para mantener la consistencia de las ventas y órdenes.
